# Security

If you find a security problem in Clipmunk (for example a way to make it run something it shouldn't, or to leak someone's Discord webhook), please email **praetorlabs@gmail.com** instead of opening a public issue. You'll get a reply as soon as possible, and a fix will ship as a normal update.

Only the latest version gets fixes. Clipmunk updates itself, so most people will get them within a day.

A Discord webhook link or Clipmunk invite lets anyone who has it post to that channel. That's how webhooks work, not a Clipmunk bug: if one leaks, delete the webhook in Discord (Edit Channel → Integrations → Webhooks) and make a new one.
